## Cross-family decisions

1. Prompt creation family must be split by user intent, not by old source title:
   - Prompt Generator: create a strong prompt from a goal.
   - Prompt Enhancer: improve an existing prompt.
   - Prompt Reliability Audit: identify ambiguity, hallucination openings, missing context/constraints.
   - Reverse Prompt Engineer: infer a plausible prompt/spec from an output.
   Variants such as concise, clarification-first, and token-efficient live inside these cards.

2. Continuity family:
   - Continue/Recap, Context Migration, Session Continuity should become one family with modes rather than three unrelated cards, unless full-text comparison reveals materially different outputs.

3. Writing-humanization family:
   - Human-like writing constraints merge with /NoAIWriting and related natural-writing commands. Preserve concrete useful constraints; discard AI-detector gaming claims.

4. Research family:
   - Literature Gap remains distinct.
   - Deep Research Prompt Generator is meta-level and should not compete with /DeepHunt unless it adds a genuinely reusable prompt-construction workflow.
   - LLM Researcher becomes Paper/Concept Research, not an LLM persona.

5. Image prompts are not deleted merely for being misplaced. Move to image families and judge visual distinctiveness there.

## Editorial principle reinforced

A useful capability survives even when its source prompt is poorly engineered. The canonical rewrite should use clear task, relevant context, meaningful constraints, and explicit expected output. Persona claims, fake expertise years, model branding, unsupported autonomy, and decorative verbosity are not quality signals.
